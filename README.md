One line roasting the AI agent its own team built. `main.ts` writes the
entry to `/output/entry.txt`:

> My agent rewrote one joke three times, turned itself in to its own safety checker, and asked permission to tell it.

Run it with Node 22 or later:

```sh
node main.ts
```
